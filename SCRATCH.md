# lemoncrow-live-check

Scratch repository for live checks of the LemonCrow Review GitHub Action.

Each `replay/pr-N` pull request replays a real, already-merged pull request of
[olaryn-lab/trevra](https://github.com/olaryn-lab/trevra) onto a copy of its base
(`base/pr-N`). The code is Trevra's; nothing here is maintained.
